# Docs

These documents describe the game that the group plays and the desktop app that supports it.

| Folder | Contents |
| --- | --- |
| [gameplay](gameplay/README.md) | How the group plays the game: characters, stats, sessions and turns, checks, the economy, projects, research, and notes. |
| [app](app/README.md) | What the app is for, what it does today, what the group needs from it, and the feature catalogue of the app. |

## Which folder to use

- A gameplay document describes what the players and the game master do. It does not describe the app.
- An app document describes what the app does or must do. When a requirement comes from a gameplay rule, the app document links to that rule.

Both folders group their documents by domain: world, sessions, economy, and knowledge. The app folder also has product and platform. Each of the two folders has a `README.md` that lists all its documents. [The glossary](glossary.md) fixes the meaning of each term.

# Characters

Each character is a real historical person. Each character has a family, an education, a work history, and a role in the world.

## Starting a character

A player can choose any historical person. The game master sets the starting stats and resources from that person's real life.

## Character development

The game master decides when [stats](stats.md) change. Changes follow game events, which can include education or actions in the relevant area. A change has no typical size. The game master sets each change and can change both sides of a pair together.

## Death and the next character

The game master decides when a character dies. The real death date is a guide, and play can change it.

After a death, the player chooses the next character freely. The next character can be an heir or any other historical person. Inheritance follows the law and custom of the character's society. So an heir can receive the assets, and an unrelated person does not.

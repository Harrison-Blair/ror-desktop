# Setting

The game is a political roleplaying simulation. Each player plays a real person from history in an alternate version of the world.

The campaign is a sandbox. Each player sets their own aims. The campaign has no end condition.

## Start of the campaign

The players choose the start date. The world can follow real history at the start, or it can start from a divergence. The current campaign is the third campaign of the group. So far, it followed real history.

## Real history during play

After the players act, the game master decides which real events still happen. The game master describes these events in the [interterm](../sessions/turn-order.md#the-interterm).

## What the game master decides

The game master decides these items case by case. The group keeps them without a fixed rule:

- Whether an action needs a skill check, and the target.
- Starting stats and resources.
- How and when two actions that conflict resolve.
- The size of a stat change.
- What counts as a major action.
- Project costs, setbacks, and completion.
- Which real events still happen.
- Campaign prices.
- When a character dies.

The game master also plays all people who are not player characters.

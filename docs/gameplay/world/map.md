# Campaign map

The group keeps one campaign map in Google Earth. The map shows what characters built, the places that characters are involved in, and other important information.

## Marks

Each mark is an area, a line, or a point with a name. Most marks are areas. For example:

- An area can show a company headquarters, a factory, an oil field, or a suspected base.
- A line can show a railway, a pipeline, or the roads in a town.

Most marks are in one folder for each character. Some marks are outside a folder. The marks have no descriptions. Many marks have only a name, and some have the default name "Untitled polygon".

## Who edits the map

Each player usually draws the marks of their own character in the folder of that character. The game master also adds marks. The map has no restrictions, so anyone in the group can change any folder.

## When the group uses the map

The group uses the map during [player turns](../sessions/turn-order.md#player-turns) and in [the interterm](../sessions/turn-order.md#the-interterm). Players also add or update marks [between sessions](../sessions/turn-order.md#between-sessions).

## KML export

The group can download the map as a KML file. KML is the file format that Google Earth uses for marks. The file keeps the folders, and the name and shape of each mark. One export of the current campaign has 90 marks: 64 areas, 23 lines, and 3 points.

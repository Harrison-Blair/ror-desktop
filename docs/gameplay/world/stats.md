# Stats

A character has 8 stat pairs. Each pair has two stat sides with opposed ideas. The game master can rename the pairs. These are the default names:

| Left side | Right side |
| --- | --- |
| Scientific | Religious |
| Rehabilitative | Punitive |
| Progressive | Conservative |
| Globalist | Isolationist |
| Communist | Capitalist |
| Regulationist | Laissez Faire |
| Environmentalist | Industrialist |
| Revolutionary | Reformist |

Each side has its own value from 1 to 100. A high value on one side does not limit the other side.

[Skill checks](../sessions/skill-checks.md) describes how a stat affects a roll. [Characters](characters.md#character-development) describes how stats change.

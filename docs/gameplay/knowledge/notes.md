# Notes

Each player and the game master keep their own notes about actions and events. The documents vary in format.

- Most players keep one or two Markdown documents for all their notes.
- Some players keep a to-do list of goals and future plans.
- The game master made a character sheet graphic for each character. It shows the picture, the name, and the stats.

[Projects](projects.md#how-players-keep-project-notes) describes one notes collection in detail.

## Who can read notes

The group usually sits together and listens to each player's turn.

The group can read a player's notes by default. For example, one character funds another character to make products. The player who makes the products can read the buyer's notes to see what the buyer ordered. Today, the buyer and the producer each keep a note about the same order.

A player can make a note private. Other players cannot read a private note.

The game master can read every player note, including private notes.

The game master's notes are hidden from players by default. A note becomes visible to players only when the game master shares it. Sharing reveals the whole note to the whole group.

A user who can read a note can also edit it. The game master can also edit private notes.
